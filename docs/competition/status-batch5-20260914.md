## 燧原配方最终边界（平台四轮实证）

| kernel 形态 | 配方（BLOCK 4096 + grid 封顶 24 + grid-stride） | 实证 |
| --- | --- | --- |
| streaming elementwise | ✓ +19%~+113% | T73/T75/T71/T62 |
| scatter（散乱 store） | ✗ -7% | T61 e8 |
| row-reduction（行归约） | ✗ -19% | T68 e4 |

机理：封 24 后并行度只有 24——streaming 用宽 BLOCK 补偿（4096 lane），
scatter 与行归约的并行度无法用 BLOCK 宽度补偿。燧原轴的可复制增益
已全部收割；剩余燧原差距（T73 2.10 vs 2.95）需 8192 或新形态。
