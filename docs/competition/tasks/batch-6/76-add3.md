# add3 (elementwise/add3)

## 任务描述

三路 elementwise 加法，保留双重舍入：`out = bf16(bf16(a + b) + c)`。
两步舍入是契约的一部分 —— 与未融合的 `(a + b) + c` 逐位一致，因此提交不得
在 fp32 中累加后只舍入一次。

## 接口签名

```python
def reference(a, b, c)
```

> 选手实现的函数签名需与上述完全一致。

## 计算定义

- `a`、`b`、`c`：同 shape 连续 CUDA bf16 张量；numel 为 16 的倍数。
- 计算流程：

  ```
  out = (a + b) + c
  ```

## 正确性判别标准

标准 per-dtype tolerance（bf16 主导）。

## 参考实现

```python
def reference(a, b, c):
    return (a + b) + c
```
