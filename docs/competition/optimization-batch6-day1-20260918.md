## 机制规律沉淀（D1 新增）

1. **静态展开**（constexpr + static_range）：循环控制开销在平台编译器
   远贵于 NVIDIA 代理；适用边界=循环体有实质控制/计算（T81 +27%
   vs T80 拷贝循环中性）。TB 3.07→3.95 三连兑现。
2. **warps 饥饿**（上游 PR #26856 公式）：宽 tile × 默认 4 warps 线程
   不足——CUDA 类 +17%（天数）、沐曦 +19~28%（T81/T80）；最优 warps
   按芯分化（天数/燧原偏好 4），沐曦/海光线程上限 512/1024@ws64。
3. **persistent 族**：copy/broadcast +23~97%，gather 零或负（T62/T78/
   T76 ✓，T63/T79 ✗）。
4. **BLOCK 阶梯峰值按访存形态**：gather 峰 4096（T63），纯 streaming
   8192 仍上行（T76 add3 +21%）。
5. **融合 vs 分离、宽 tile 按芯组合**：GCU 偏好 clone+patch 分离与单趟
   宽 tile；沐曦宽 tile 收益有限（+1.7%）与海光（+12%）分化。
