### 机制沉淀（当日新增，全部平台实证）

1. **宽度阶梯按 op×chip 分化**（unpad 实测全表）：
   华为 2048→32768 单调升至 16384 峰（442-507）；燧原峰 16384 且需
   tiles≤max(1,24//bs)；海光方向相反（4096 腰斩，峰 1024）；沐曦对
   宽度/warps/stages 全免疫；昆仑峰 16384（1024 灾难性 6.1）；
   card_a(_nvidia) 8192-16384 饱和 ~495；card_b(_amd) 窄向 2048-1024 ~278。
2. **GCU 程序模型三败一胜**：行形式（0.5-0.8）、flat 多程序（0.2-0.5）、
   2D tile（0.53）全病理；唯一可行 = 少程序（≤24）+ 超宽块
   （16384-65536）。三题验证（relu2 3.9 / unpad 55 / topk_sum 1.03）。
   输出分区均衡内核也败（19.7）——GCU 不奖励负载均衡，奖励形态。
3. **vendor 槽位隔离**：七槽齐备（ascend/enflame/hygon/metax/nvidia/
   amd/kunlunxin）后 generic 只跑天数——单变量逐芯归因的完全体。
   card_a=_nvidia、card_b=_amd 映射当日确认。
4. **uint32 位宽重解释**（天数/沐曦）与**燧原输出分区**均判负——三芯
   的 1.4-2× 结构缺口（沐曦 379/天数 480/燧原 148 的榜首专属）今日
   已知轴穷尽。
5. **慢窗/窗口重掷协议有效**：e14 燧原 2.3（同字节 e13 读 56.5）重掷
   恢复；e17 抽中华为 507/卡A 504 高位 +9.7 均值。
6. int64 化成本 ~3-4%（天数/沐曦），正确性必需不回退。
